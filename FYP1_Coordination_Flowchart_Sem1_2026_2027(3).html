One-time Supabase database setup (SQL) 
create table if not exists public.fyp1_planner_state (
  user_id uuid not null references auth.users(id) on delete cascade,
  planner_key text not null,
  state jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now(),
  primary key (user_id, planner_key)
);

alter table public.fyp1_planner_state enable row level security;

-- Re-running this setup is safe.
drop policy if exists "Users manage own FYP1 planner" on public.fyp1_planner_state;
create policy "Users manage own FYP1 planner"
on public.fyp1_planner_state
for all
to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

grant usage on schema public to authenticated;
grant select, insert, update, delete on table public.fyp1_planner_state to authenticated;

Coordination Logic

Pre-semester readiness: project-area refresh → verify capacity → room booking → matching → release assignment → Teams/Telegram → submission links.
Official dates: follow the Semester 1 2026/2027 FYP milestone/planner. Do not move official deadlines in this page unless the College calendar changes.
Reminder rule: issue the main reminder 7 days before each deadline/event. For multi-day oral presentation, send a reminder before the window opens and another before it closes.
Source notes: official FYP1 dates are from the uploaded “MIlestone FYP Sem1, 2026_2027 to all FYP Coordinators.xlsx” and “Sem 1 2026-2027 FYP Planner_By Tan.050826.1600.xlsx”. The pre-semester coordination dates are suggested operational dates, not official College deadlines.
